# Project context and agent instructions
Six bachelors in a rented flat miss municipal wet/dry waste collection on Thursdays and Sundays, causing waste accumulation and flies. Success is physical disposal, not notification delivery. Keep the system inexpensive, low friction, and hardware-free. Default IST schedule: Wed/Sat 21:00 assignment, Thu/Sun 06:30 reminders every five minutes, backup from 07:00, configurable cutoff. Fair random rotation, persisted state, authenticated completion, bounded reminders, restart recovery. Never commit secrets. Use small logical commits on feature/ branches. Do not introduce a frontend or microservices until the bot workflow is validated. Next tasks: injectable clock and automated tests, configurable schedule and test mode, onboarding, missed-duty summary, robust notification outbox and monitoring. Document changes and run build/tests before claiming success.
